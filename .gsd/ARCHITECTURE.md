## Overview

**maiPaQueueCheck PH** is a real-time queue management system for maimai DX rhythm game sessions. The application enables players at arcade locations (branches) to manage song queue queues, track best scores, and collaborate on song discussions.

It's built as a modern React SPA with responsive design, powered by Supabase for real-time data synchronization and user authentication.

## Data Flow

### Queue Management Flow

1. **User enters queue page** → QueueManager loads
2. **useQueueData hook** polls/subscribes to Supabase for changes
3. **Real-time updates** arrive from Supabase (another player added)
4. **Queue notification** displays "Now playing: {Player 1}"
5. **User edits queue** → QueueActions hook
6. **API call** to queue service (upsert/delete/reorder)
7. **Supabase validates** (RLS, permissions)
8. **Changes broadcast** to all listening clients
9. **UI updates** across sessions via context

### Authentication Flow

1. User visits app → AuthContext checks session
2. If no session → LoginForm displays
3. User submits credentials → authService.signIn()
4. Supabase returns JWT + user profile
5. AuthContext stores token in localStorage
6. RLS queries now include user context
7. Protective hooks (useAuth, usePermissions) enable auth-gated features

### Song Data Flow

1. **App initializes** → SongDatabaseProvider loads all songs
2. **useEffect** fetches from Supabase (or cached JSON)
3. **Data stored** in context (not page-level state)
4. **SongsPage queries** context for search/filter
5. **User views song** → Ratings/comments loaded separately
6. **Cache refreshes** on periodic timer or manual refresh

## Key Architectural Decisions

1. **Context + Hooks over Redux**: Simpler mental model for mid-size app
2. **Supabase Realtime**: Real-time queue without custom WebSocket servers
3. **Client-side Song Cache**: Avoid N+1 queries, improve search performance
4. **Feature Flags via Context**: Simple gates without external service
5. **Domain-specific Services**: Organized by bounded contexts (queue, admin, etc.)
