## Build & Runtime Details

### Build Output

```
Input:  src/** (React JSX + CSS)
        ↓
Vite:   Bundle splitting, code analysis
        ↓
Terser: Minification
        ↓
Compression: gzip + brotli
        ↓
Output: dist/
        ├── index.html
        ├── assets/
        │   ├── index-*.js (main bundle)
        │   ├── vendor-*.js (dependencies)
        │   ├── queue-page-*.js (lazy-loaded)
        │   ├── songs-page-*.js (lazy-loaded)
        │   ├── index-*.css (styles)
        │   ├── *.gz (gzip versions)
        │   └── *.br (brotli versions)
        └── stats.html (analysis, if --mode analyze)
```

## local Development Setup

### Install

```bash
npm install
```

### Scripts

```bash
npm run dev              # Start dev server (localhost:5173)
npm run build           # Compile for production
npm run build:analyze   # Build + open bundle analyzer
npm run build:bookmarklet # Build browser bookmarklet
npm run lint            # Check code quality
npm run lint:fix        # Auto-fix linting issues
npm run preview         # Preview production build locally
```

### Environment Setup

1. Create `.env.local` with Supabase credentials
2. Run `npm install` to fetch dependencies
3. Run `npm run dev` to start Vite server
4. Open http://localhost:5173 in browser

## Key Tooling Decisions

| Decision | Rationale |
|----------|-----------|
| **Vite over CRA** | Faster builds, better HMR, modern ESM-first |
| **Mantine over custom/Material** | Complete component library, accessibility out of box |
| **Supabase over Firebase** | PostgreSQL flexibility, better for complex queries |
| **Context API over Redux** | Simpler mental model for mid-size app (not enterprise) |
| **ESLint over Prettier alone** | Catches logical issues beyond formatting |
| **Zod over TypeScript only** | Runtime validation, better error messages |
